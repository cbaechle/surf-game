# Surf's Up

A webcam surfing game for a TV: hold your arms out like a surfer, tilt them to steer, and ride
the wave with your own picture on the board.

**Play: https://cbaechle.github.io/surf-game/** (desktop Chrome, a webcam, and room to stand back)

Everything runs in your browser. The camera picture never leaves your computer.

This repository holds only the compiled site (build 865ca04).
